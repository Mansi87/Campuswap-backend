CampusSwap

CampusSwap is a **swipe-based campus marketplace** where students can buy and sell second-hand items within their college community. Inspired by swipe discovery similar to Tinder, the platform makes product browsing simple and interactive.
Users can list products, explore items through swipe cards, chat with buyers/sellers in real time, and receive intelligent price and product recommendations.

Features:
* Swipe-based product discovery
* Product listing with image upload
* Search and filtering
* Real-time buyer–seller chat
* ML-based price and product recommendation

Tech Stack
Backend:Java, Spring Boot, REST APIs, WebSockets, JWT
Frontend:React
Database:PostgreSQL
ML:Python, Scikit-learn
Storage:Cloudinary
Tools:Git, Docker, Maven

Quick Start:
bash:
git clone https://github.com/yourusername/campusswap.git
cd campusswap
mvn spring-boot:run
